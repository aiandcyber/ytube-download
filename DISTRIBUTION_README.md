# Download YouTube (desktop)

Windows and Mac apps for **AI-forAll Tools → Download YouTube**.

- Downloads run on **your computer** (not on our servers).
- Sign in with the **same account** as [Tools](https://tools.ai-forall.org) after the free first download.

## Downloads

Use the simple download page: https://aiandcyber.github.io/ytube-download/

Choose **Windows** or **Mac**, then press **Download**.
