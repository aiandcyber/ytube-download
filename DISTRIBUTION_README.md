# Download YouTube (desktop)

Windows and Mac installers for **AI-forAll Tools → Download YouTube**.

- Downloads run **on your computer** (not on our servers).
- Sign in with the **same Auth0 account** as [Tools](https://tools.ai-forall.org) after the free first download.
- Source code lives in a separate developer repo; this repository is for **release files only**.
